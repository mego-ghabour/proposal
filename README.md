# منظومة العروض الفنية والمالية الذكية (Fkretk Proposal AI System)

منظومة متكاملة طُوّرت خصيصاً لـ **وكالة فكرتك الرقمية (Fkretk Agency)** لتوليد وإدارة العروض الفنية والمالية (Proposals) للعملاء بالاستعانة بالذكاء الاصطناعي (**Google Gemini API**) عبر لوحة تحكم سريعة (Single Page Application)، مع إتاحة العرض للعميل عبر رابط مباشر متطابق تماماً مع أرقى معايير التصميم المعتمدة في الوكالة.

---

## 🌟 أبرز مميزات النظام

### 1. لوحة تحكم ذكية مدعومة بالـ AI (Single Page UX)
- **تجربة تفاعلية فائقة السرعة**: مبنية باستخدام **Laravel 11 + Alpine.js + Tailwind CSS** بدون إعادة تحميل للصفحات.
- **معالج إنشاء العروض في 3 خطوات ذكية (3-Step AI Wizard)**:
  1. **الخطوة الأولى (فكرة المشروع)**: يُدخل مسؤول المبيعات فكرة ومتطلبات العميل، واسم العميل والجهة والعملة.
  2. **الخطوة الثانية (الاستيضاح وتقدير السعر)**: يحلل Gemini الفكرة فورياً، ويقترح **المدى السعري التقريبي** و**الجدول الزمني**، ويطرح **3 إلى 4 أسئلة استيضاحية تفاعلية** (النطاق، المنصات، بوابات الدفع، إلخ) مع تحديد الخيار الموصى به تلقائياً.
  3. **الخطوة الثالثة (مراجعة وتخصيص العرض الكامل)**: يولد Gemini العرض الفني والمالي الكامل بهيكل احترافي جاهز للتحرير (الموديولات، الباقات، الأسعار، دورة العمل، مراحل التنفيذ، الشروط والضمانات)، مع إمكانية التعديل بضغطة زر وحفظه فوراً.

### 2. واجهة العرض العامة للعميل (Shareable Client Proposal View)
- رابط عام موثق لكل عميل: `/p/{uuid}` أو `/proposal/{slug}`.
- **تصميم مطابق 100% للتصميم الفرونت المعتمد للوكالة**:
  - شريط مؤشر تقدم القراءة والـ Scrollspy التفاعلي.
  - هيدر فخم ببيانات العميل وموجز الاستثمار والمنصات.
  - **قسم المشكلة والحل**: ركائز المشروع ومقارنة مباشرة بين الوضع التقليدي وحل وكالة فكرتك.
  - **قسم دورة العمل**: المراحل الهندسية الأربعة لتشغيل المنظومة.
  - **قسم الموديولات الفنية**: استعراض تفصيلي للمميزات مع الأيقونات والوسوم.
  - **قسم العرض المالي والباقات**: باقات استثمارية (الباقة الأساسية والباقة الشاملة الموصى بها)، مع جدول مقارنة تفصيلي.
  - **قسم مراحل التنفيذ وجدول الدفعات**: مراحل الأسابيع والضمانات الفنية الشاملة.
  - **نموذج اعتماد العرض الفوري (Acceptance Modal)**: يتيح للعميل اختيار الباقة وتأكيد اعتماده، ويقوم النظام بتحديث حالة العرض في لوحة التحكم وتوجيه العميل مباشرة إلى واتساب مسؤول المبيعات.
  - **دعم كامل للطباعة وتحويل العرض إلى PDF** بنقرة زر واحدة.
  - **بطاقات المعاينة الاجتماعية (Open Graph)**: تظهر عنوان العرض وشعار الوكالة والوصف تلقائياً عند إرسال الرابط عبر واتساب.

### 3. البراندينج وإعدادات الوكالة (Database Seeder + Live Settings)
- **بيانات افتراضية جاهزة (Seeded)**:
  - اسم الوكالة: وكالة فكرتك الرقمية (Fkretk Agency).
  - الشعار اللفظي: شريكك التقني الموثوق لبناء المنظومات والحلول الرقمية الذكية.
  - أرقام التواصل والواتساب والبريد والموقع الجغرافي وحسابات السوشيال ميديا (LinkedIn, Twitter/X, Instagram, Behance).
  - شعار الوكالة والخطوط الرسمية (Thmanyah Sans, Cairo, Tajawal).
- **إمكانية التعديل في أي وقت**: من خلال تبويب "إعدادات الوكالة و Gemini" في لوحة التحكم.
- **إدارة مفتاح Gemini API وموديل الذكاء الاصطناعي**:
  - إمكانية حفظ واختبار المفتاح مباشرة بضغطة زر `⚡ فحص واختبار عمل المفتاح`.
  - دعم موديلات `gemini-2.0-flash` و `gemini-1.5-flash` و `gemini-1.5-pro`.

## 🚀 تشغيل النظام

### 1. تشغيل السيرفر
```bash
php artisan serve
```
سيعمل النظام مباشرة على الرابط:
- لوحة التحكم: **[http://127.0.0.1:8000/dashboard](http://127.0.0.1:8000/dashboard)**
- نموذج العرض المعتمد (B2B Cosmetics & Pharma): **[http://127.0.0.1:8000/p/a1b2c3d4-e5f6-7890-abcd-ef1234567890](http://127.0.0.1:8000/p/a1b2c3d4-e5f6-7890-abcd-ef1234567890)**

### 2. إعادة تهيئة قاعدة البيانات والتغذية الأولية (Seeder)
```bash
php artisan migrate:fresh --seed
```

### 3. تشغيل الاختبارات الآلية
```bash
php artisan test
```

## 📁 هيكلة المشروع

- `app/Models/Proposal.php`: نموذج بيانات العرض الفني والمالي وروابط المشاركة.
- `app/Models/CompanySetting.php`: نموذج إعدادات الوكالة والبراندينج ومفتاح Gemini.
- `app/Services/GeminiProposalService.php`: محرك الذكاء الاصطناعي المسؤول عن تحليل الأفكار، تقدير الأسعار، توليد الأسئلة، وصياغة وثيقة العرض الكاملة.
- `app/Http/Controllers/ProposalDashboardController.php`: تحكم لوحة المبيعات والـ APIs الخاصة بـ SPA.
- `app/Http/Controllers/PublicProposalController.php`: تحكم العرض العام للعميل واعتماد العروض.
- `resources/views/dashboard/index.blade.php`: لوحة التحكم التفاعلية السريعة (SPA).
- `resources/views/proposals/show.blade.php`: الواجهة الفخمة للعرض المالي والفني للعميل.
- `database/seeders/DatabaseSeeder.php`: تغذية البيانات الأساسية وهوية الوكالة وعرض تجريبي متكامل.
